# Alvacom Homes · Off-Market

Professional DFW off-market map for **Alvacom Homes**.

- Brand: **Alvacom Homes** (primary) with smaller **Off-Market** label
- Data: published Google Sheet CSV (Wholesalers feed)
- Map + list views
- Each listing opens a **property one-pager** built from email/sheet fields (subject, comments, beds/baths/sqft/year, wholesaler, print/PDF, Maps / Street View, shareable `#p=` link)

## Deploy (Netlify)

Import this GitHub repo. Publish directory = site root (no build command). Link the existing `dfw-wholesales` Netlify site to `main` for auto-deploys.
